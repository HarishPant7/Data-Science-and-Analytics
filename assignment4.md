## Standardization 

Standardization is a data preprocessing technique used to bring numerical data into a common scale. It changes data based on its mean and standard deviation. In this process, the mean becomes 0 and the standard deviation becomes 1. It is also known as Z-score normalization. Standardization helps make different features comparable and prevents large values from dominating smaller values. It is commonly used in machine learning algorithms such as KNN, SVM and Logistic Regression. Unlike Min-Max normalization, it does not limit data values between 0 and 1. It is useful when working with data that has different ranges. However, it can be affected by outliers.
