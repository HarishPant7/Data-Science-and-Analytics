## Normalization and Its Types 

Normalization is a data preprocessing technique used to bring numerical data into a common scale. It makes data easier to compare and helps improve the performance of some machine learning algorithms.

### Types of Normalization

**1. Min-Max Normalization**

It converts data values into a fixed range, usually between 0 and 1.

**2. Z-Score Normalization**

It changes data based on its mean and standard deviation.

**3. Decimal Scaling**

It normalizes data by moving the decimal point.

**4. Unit Vector Normalization**

It scales data so that the length of a vector becomes 1.

**5. Robust Scaling**

It scales data using the median and interquartile range (IQR) to handle outliers.
